# MacCleaner

MacCleaner 是一款原生 macOS 工具，提供缓存清理、软件卸载、空间分析、系统维护、性能监控、开发项目清理及截图标注。

## 下载与更新

[下载 MacCleaner 1.0.0 DMG（Build 1）](https://github.com/reincc/MacCleaner/releases/download/v1.0.0/MacCleaner-1.0.0.dmg) · [查看发布说明](https://github.com/reincc/MacCleaner/releases/tag/v1.0.0) · [所有版本](https://github.com/reincc/MacCleaner/releases)

支持 macOS 13 及以上版本，兼容 Apple Silicon 和 Intel。应用已完成 Developer ID 签名及 Apple 公证。

1. 打开 DMG，将左侧 **MacCleaner** 拖到右侧 **Applications** 文件夹。
2. 从“应用程序”打开 MacCleaner，随后可推出磁盘映像。
3. 截图功能需要屏幕录制权限；访问受保护目录时按需开启完全磁盘访问权限。

首次启用此更新渠道需要手动安装。此后可通过应用菜单、设置页或状态栏右键菜单检查更新，也支持自动检查。更新清单和安装包均使用 Ed25519 签名校验。

若检查更新提示应用仍位于下载位置，请完全退出 MacCleaner，在 Finder 中将应用移入“应用程序”，再从那里重新打开。不要直接从下载目录或 DMG 内运行。

Release 同时提供 [ZIP 下载](https://github.com/reincc/MacCleaner/releases/download/v1.0.0/MacCleaner-1.0.0.zip)、DMG 独立 SHA-256 校验文件、原有 `SHA256SUMS`、内置 Mole 对应版本的源码归档与第三方许可说明。
