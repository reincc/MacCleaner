# MacCleaner

MacCleaner 是一款原生 macOS 工具，提供缓存清理、软件卸载、空间分析、系统维护、性能监控、开发项目清理及截图标注。

## 下载与更新

[下载 MacCleaner 1.0.0（Build 1）](https://github.com/reincc/MacCleaner/releases/download/v1.0.0/MacCleaner-1.0.0.zip) · [查看发布说明](https://github.com/reincc/MacCleaner/releases/tag/v1.0.0) · [所有版本](https://github.com/reincc/MacCleaner/releases)

支持 macOS 13 及以上版本，兼容 Apple Silicon 和 Intel。正式安装包已完成 Developer ID 签名及 Apple 公证。

下载 ZIP 并解压，将 `MacCleaner.app` 放入“应用程序”文件夹后打开。截图功能需要屏幕录制权限；访问受保护目录时按需开启完全磁盘访问权限。

首次启用此更新渠道需要手动安装。此后可通过应用菜单、设置页或状态栏右键菜单检查更新，也支持自动检查。更新清单和安装包均使用 Ed25519 签名校验。

Release 附带 `SHA256SUMS`、内置 Mole 对应版本的源码归档与第三方许可说明。
