# MacCleaner

MacCleaner 是一款原生 macOS 工具，提供缓存清理、软件卸载、空间分析、系统维护、性能监控、开发项目清理及截图标注。

## 下载与更新

[查看发布版本](https://github.com/reincc/MacCleaner/releases)

目前更新服务已初始化，正式安装包尚未发布。`update-channel` 仅用于初始化更新服务，不是可安装的软件版本。

带有更新配置的 MacCleaner 可以通过应用菜单、设置页或状态栏右键菜单检查更新。更新清单和安装包均使用 Ed25519 签名校验。

## 项目状态

此仓库目前用于发布更新和项目信息。应用源码尚未公开。
